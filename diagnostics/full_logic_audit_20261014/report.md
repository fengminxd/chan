## 1. P2：MACD 候选降为盘整背驰时，证据时间没有随分类更新

位置：`chan_theory.py:343–348`，`divergence_candidates`。

`kind` 无论取 `trend` 还是 `consolidation`，都使用当前中枢关系。但是只有 `trend` 分支汇总相邻中枢的 `updated_at`；降为盘整时，返回的证据时间仅汇总成枢、进入走势、离开走势，遗漏引发降级的后续延伸走势。

最小复现端点序列：

```text
0 → 12 → 6 → 10 → 7 → 15 → 13 → 18 → 14 → 16 → 11
```

使用连续完成走势夹具，相邻端点间隔 4 小时，每条走势在结束后 1 小时可用；指标输入采用明确的合成 MACD 点，以隔离结构分类与证据传播。

| 可见前缀 | 同一候选 `L1:E1:D:8` | 返回证据时间（UTC） |
| --- | --- | --- |
| 截至 14→16 | `trend` | 2024-01-02 13:00 |
| 增加 16→11 | `consolidation` | **仍为 2024-01-02 13:00** |

新增走势在 **2024-01-02 17:00** 才可用。它把后中枢的波动下界压至 11，破坏原来的向上相离关系。因此降级后的分类不能声称在 13:00 已有完整依据。

影响：候选快照和报告中的 `evidence_at` 失真。首次观察时间仍由回放另行记录，不能据此认定回放成交已使用未来数据；本例也不是新增的严格背驰确认。修复方向：两种分类均传播用于比较的中枢状态证据，并保留分类修订的观察时间；涉及离开后范围回算时还应核对 `closed_at` 依赖。

证据：`test_findings.py::test_changed_divergence_classification_carries_new_evidence`。

## 2. P2：严格背驰审计可把不属于 c 的中枢当成 c 的内部中枢

位置：`chan_dynamics.py:162–170`，`audit_divergence`。

`c_internal_level_and_containment` 只检查级别，以及 `c.start <= z.start < z.formed_at <= c.end`。没有检查中枢完整时间范围、价格范围，或中枢 ID 与 `c.center_ids` 的对应。`source_lineage` 直接信任默认值为 `True` 的参数。

在现有标准正例夹具上分别做以下单项变更，当前函数均返回 `confirmed_under_policy`、`strict_divergence_confirmed=True`：

1. 中枢 `end` 延至 c 结束后 20 小时，并同步延后 `updated_at`。
2. 中枢所有价格统计整体上移 1,000，完全离开 c 的价格范围。
3. 中枢 ID 改为 `UNRELATED:*`，与 c 声明的 `center_ids` 不一致。

这些结果证明“内部包含”和“来源检查”的断言比实际校验更强。修复方向：校验完整中枢时间范围及价格包含；验证 ID 唯一、集合一致及归属关系，不能仅使用一个默认通过的布尔值代表来源证明。

**适用范围限定：这是独立审计函数的缺口。** 正常 `analyze_dynamics` 从分解注册表收集中枢，还检查内部 ID 数量/唯一性及组成走势完成状态；本轮没有证明正常 OHLC 流程可以生成上述三种坏输入。不要把这些接口反例写成真实行情已经出现严格背驰误确认。

证据：`test_findings.py` 中其余三个测试。
